# ⚡ QUICK REFERENCE - Comandos Rápidos

**Guía rápida para ejecutar el sistema.**

---

## OPCIÓN 1: INSTALACIÓN AUTOMÁTICA (Recomendado - 3 min)

### Windows
```
1. Busca la carpeta PROYECTO JORGE
2. Click derecho en setup.bat
3. "Ejecutar como administrador"
4. Espera a que termine
```

### Linux/Mac
```bash
cd PROYECTO\ JORGE
chmod +x setup.sh
./setup.sh
```

---

## OPCIÓN 2: INSTALACIÓN MANUAL (5 min)

### Windows CMD
```cmd
cd backend
npm install
cd ..
cd frontend
npm install
```

### Linux/Mac Terminal
```bash
cd backend && npm install && cd ..
cd frontend && npm install && cd ..
```

---

## CREAR BASE DE DATOS (Primero esto)

### Si tienes PostgreSQL instalado
```bash
psql -U postgres
CREATE DATABASE iot_inundaciones;
\q

psql -U postgres -d iot_inundaciones -f database/init.sql
```

### Si tienes MySQL instalado
```bash
mysql -u root -p < database/init.sql
```

---

## EJECUTAR SISTEMA (Después de instalar BD)

### Terminal 1: Backend
```bash
cd backend
npm run dev
```

Verás:
```
✓ Servidor corriendo en: http://localhost:3000
📚 API Base: http://localhost:3000/api
```

### Terminal 2: Frontend
```bash
cd frontend
npm start
```

Se abrirá automáticamente http://localhost:3000

## TROUBLESHOOTING RÁPIDO

| Problema | Solución |
|----------|----------|
| `setup no funciona` | Click derecho → Ejecutar como admin |
| `npm no reconocido` | Instalar Node.js desde nodejs.org |
| `Puerto 3000 ocupado` | Cambiar: PORT=3001 npm run dev |
| `BD no conecta` | Verificar MySQL/PostgreSQL corriendo |
| `Node modules error` | Borrar carpeta, reintentar npm install |
