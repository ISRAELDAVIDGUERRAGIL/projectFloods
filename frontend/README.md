// Frontend - Dashboard IoT Inundaciones

## Descripción

Dashboard web desarrollado con React para visualización en tiempo real del sistema IoT.

## Estructura

```
frontend/
├── public/
│   ├── index.html
│   └── favicon.ico
├── src/
│   ├── components/      # Componentes React reutilizables
│   ├── pages/          # Páginas principales
│   ├── services/       # Servicios API
│   ├── hooks/          # Custom hooks
│   ├── context/        # Context API
│   ├── styles/         # Estilos CSS
│   ├── utils/          # Utilidades
│   ├── App.js          # Componente principal
│   └── index.js        # Punto de entrada
├── public/
├── package.json
└── README.md
```

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm start
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.

## Build

```bash
npm run build
```

## Características

- ✅ Autenticación de usuarios
- ✅ Dashboard en tiempo real
- ✅ Gráficos históricos
- ✅ Alertas en tiempo real
- ✅ Configuración de dispositivos
- ✅ Control remoto
- ✅ Responsive design
- ✅ Tema oscuro/claro

## Dependencias Principales

- react: Library
- react-router-dom: Enrutamiento
- axios: Cliente HTTP
- recharts: Gráficos
- zustand: State management
- tailwindcss: Estilos
